# Wireframe comentado — LP de alta conversão (serviço / consultoria)

Este documento mostra a estrutura de uma landing page de serviço/consultoria seção por seção. Cada bloco traz o **wireframe** (esboço em ASCII, sem conteúdo final) e o **porquê** de cada decisão de UX e de conversão. Substitua os marcadores entre colchetes (`[AREA]`, `R$ X.XXX`, métricas) pelo conteúdo real.

---

## Curta ou longa?

As 14 seções a seguir são um **cardápio, não uma obrigação**. Escolha as que o seu caso pede e descarte o resto — uma LP pode ser longa e ainda assim limpa, desde que cada seção seja enxuta e empurre para a mesma ação.

> **Resumindo a posição correta:** formulário curto, sim, sempre. Página curta, depende — tráfego frio e oferta cara pedem mais seções; tráfego quente e oferta simples pedem menos.

**Núcleo essencial (consultoria):** 1 Hero · 3 Confiança · 4 Problema · 5 Como funciona · 7 Resultados · 8 Depoimentos · 9 Sobre · 10 Oferta · 12 CTA final.
**Adicione se houver necessidade:** 6 Serviços detalhados · 11 FAQ · 14 Popup de saída.

---

## Visão geral do fluxo

A ordem é deliberada: ganhar atenção → gerar identificação → provar competência → conduzir a uma única ação.

```
┌─────────────────────────────────────────────┐
│  navegador                                   │
├─────────────────────────────────────────────┤
│  1  Barra superior — logo + 1 CTA            │
│  2  Hero — proposta de valor + CTA           │
│  3  Barra de confiança — logos               │
│  4  Problema / dor                           │
│  5  Como funciona — 3 passos                 │
│  6  Serviços / entregáveis                   │
│  7  Resultados / métricas                    │
│  8  Depoimentos                              │
│  9  Sobre o consultor                        │
│ 10  Processo + oferta                        │
│ 11  FAQ / objeções                           │
│ 12  CTA final               ◄── destaque     │
│ 13  Rodapé                                   │
└─────────────────────────────────────────────┘
   + 14  Popup de saída (overlay, exit-intent)
```

## Seção por seção

### 1. Barra superior

```
┌─────────────────────────────────────────────┐
│ [LOGO]                     [ Agendar conversa ]│
└─────────────────────────────────────────────┘
```

Logo à esquerda e um único CTA à direita — **sem menu de navegação**. Em uma LP, o menu é uma das maiores fugas de conversão: cada link extra dá ao visitante uma rota para sair antes de agir.

- **Sem menu de navegação.** Remover a navegação costuma ser a melhoria de maior impacto e menor esforço numa LP.
- **CTA sempre acessível.** Pode ficar fixo no topo conforme a pessoa rola a página.
- **Logo discreto.** Marca presente, mas sem competir com o botão.

### 2. Hero (acima da dobra)

```
┌─────────────────────────────────────────────┐
│ CONSULTORIA EM [AREA]                         │
│                              ┌──────────────┐ │
│ Headline com a               │              │ │
│ proposta de valor            │  FOTO/VÍDEO  │ │
│ clara e específica           │   (10–15s)   │ │
│ ────────────────             │              │ │
│ ──────────────               └──────────────┘ │
│ [ Quero um diagnóstico ]                      │
│ Resposta em 24h · sem compromisso             │
└─────────────────────────────────────────────┘
```

É o que decide se a pessoa fica. Eyebrow com a categoria, headline com a proposta de valor específica, subhead que reforça o benefício, CTA primário e uma microcopy que reduz a fricção.

- **Headline no resultado do cliente.** Fale do que ele ganha, não do seu método.
- **Um único CTA primário.** Uma página, uma ação.
- **Microcopy de baixa fricção.** "Resposta em 24h, sem compromisso" dissolve a objeção logo abaixo do botão.

### 3. Barra de confiança

```
        Empresas que já confiaram no trabalho
  [logo]   [logo]   [logo]   [logo]   [logo]
```

Logos de clientes logo após o hero. É o princípio **trust-first**: mostrar credibilidade cedo, antes de pedir qualquer compromisso maior.

- **Posicionada cedo.** A confiança precisa chegar antes do pedido.
- **Tom discreto.** Em cinza, para não disputar atenção com o CTA.

### 4. Problema / dor

```
            Você reconhece esse cenário?
  ┌───────────┐  ┌───────────┐  ┌───────────┐
  │ (!) Dor 1 │  │ (!) Dor 2 │  │ (!) Dor 3 │
  │ ───────── │  │ ───────── │  │ ───────── │
  └───────────┘  └───────────┘  └───────────┘
```

Três cartões que espelham a dor do cliente para gerar identificação ("é exatamente isso que eu sinto") antes de apresentar a solução.

- **Linguagem do cliente.** Use as palavras dele, não jargão técnico.
- **Três itens.** Escaneável; mais que isso dilui a mensagem.

### 5. Como funciona

```
                  Como funciona
     (1) ────► (2) ────► (3)
   Passo 1     Passo 2    Passo 3
   ───────     ───────    ───────
```

Três passos numerados que tornam o processo concreto e reduzem a percepção de esforço e risco — a pessoa entende no que está entrando.

- **Máximo três passos.** Simplicidade transmite "isso é fácil de começar".
- **Setas guiam o olhar.** Reforçam a sequência e a leitura.

### 6. Serviços / entregáveis

```
              O que você recebe
  ┌─────────────────────┐ ┌─────────────────────┐
  │ [□] Entregável 1     │ │ [□] Entregável 2     │
  └─────────────────────┘ └─────────────────────┘
  ┌─────────────────────┐ ┌─────────────────────┐
  │ [□] Entregável 3     │ │ [□] Entregável 4     │
  └─────────────────────┘ └─────────────────────┘
```

O que a pessoa efetivamente recebe, em blocos escaneáveis. Foco em entregáveis tangíveis, não em horas ou processos internos.

- **Entregáveis concretos.** "Você recebe X" converte melhor que "fazemos Y".
- **Grid escaneável.** Ícone + título + uma linha por item.

### 7. Resultados / métricas

```
                 Resultados reais
   ┌──────────┐    ┌──────────┐    ┌──────────┐
   │  +120%   │    │   3.5x   │    │   -40%   │
   │  leads   │    │   ROI    │    │  custo   │
   └──────────┘    └──────────┘    └──────────┘
```

Prova quantitativa com números grandes. Em consultoria, resultado mensurável é o argumento mais forte que existe.

- **No máximo três métricas.** Números reais — substitua os placeholders.
- **Cor diferente do CTA.** Sinaliza "isto é prova", não "clique aqui".

### 8. Depoimentos

```
  ┌────────────────────────┐ ┌────────────────────────┐
  │ "                       │ │ "                       │
  │ ─────────────────       │ │ ─────────────────       │
  │ (o) Nome — Cargo        │ │ (o) Nome — Cargo        │
  │     Empresa             │ │     Empresa             │
  └────────────────────────┘ └────────────────────────┘
```

Citações com rosto, nome, cargo e empresa. A foto aumenta a credibilidade percebida e humaniza a prova social.

- **Inclua o rosto.** Depoimento com foto gera mais confiança.
- **Poucos e fortes.** Um ou dois depoimentos específicos valem mais que dez genéricos.

### 9. Sobre o consultor

```
  ┌──────────┐   Sobre [seu nome]
  │          │   ─────────────────────────
  │   FOTO   │   ─────────────────────────
  │          │   ───────────
  └──────────┘   [selo 1] [selo 2] [selo 3]
```

Em serviço/consultoria, a pessoa compra de uma pessoa. Rosto, bio curta conectando sua experiência ao problema dela, e selos de autoridade.

- **Foto olhando para o texto.** O olhar do rosto guia o do leitor para a mensagem.
- **Bio orientada ao cliente.** Sua trajetória traduzida no benefício para ele.
- **Selos / credenciais.** Certificações, mídia, parcerias — autoridade visível.

### 10. Processo + oferta

```
            Como trabalhamos juntos
  ┌─────────────────────────────────────────────┐
  │ Pacote / formato de trabalho     a partir de  │
  │ ─────────────────────            R$ X.XXX     │
  │ ─────────────────                             │
  │ ─────────────────            [ Agendar conversa ]│
  └─────────────────────────────────────────────┘
```

Como vocês trabalham juntos e a faixa de investimento, com o CTA repetido. Transparência de preço ("a partir de") qualifica o lead e reduz fricção.

- **Mostre a faixa de preço.** Filtra curiosos e aumenta a qualidade do contato.
- **Mesmo CTA do hero.** Consistência: uma única ação na página inteira.
- **Bloco destacado.** Borda em destaque ancora a decisão.

### 11. FAQ / objeções

```
            Perguntas frequentes
  ┌─────────────────────────────────────────  [+] ┐
  ┌─────────────────────────────────────────  [+] ┐
  ┌─────────────────────────────────────────  [+] ┐
  ┌─────────────────────────────────────────  [+] ┐
```

Acordeão que antecipa as objeções reais — preço, prazo, garantia, "serve para o meu caso?". Cada resposta remove um motivo para não agir.

- **Uma objeção por item.** Responda o que de fato trava a decisão.
- **Formato acordeão.** Mantém a página enxuta sem esconder informação.

### 12. CTA final

```
  ┌─────────────────────────────────────────────┐
  │      Pronto para dar o próximo passo?         │
  │        [ Agendar conversa gratuita ]          │
  └─────────────────────────────────────────────┘
```

Fechamento com a mesma ação única, em bloco de alto contraste. Quem rolou até aqui está pronto — não disperse com links concorrentes.

- **Repita o CTA principal.** A mesma promessa do hero, reforçada.
- **Alto contraste, zero distração.** Só a ação importa neste bloco.

### 13. Rodapé

```
  [LOGO]                  [link] [link] [link]
  Contato · Redes · Política de privacidade
```

Mínimo necessário: logo, contato, redes e política. O objetivo é manter o foco na conversão até o último pixel.

- **Sem mar de links.** Rodapé de LP não é rodapé de site institucional.

### 14. Popup de saída (exit-intent)

```
  ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░
  ░░░░┌─────────────────────────────────┐ [x] ░░
  ░░░░│  Espera! Leve algo antes de sair │     ░░
  ░░░░│  ─────────────────────────────   │     ░░
  ░░░░│  [ seu@email.com              ]   │     ░░
  ░░░░│  [ Receber material grátis    ]   │     ░░
  ░░░░└─────────────────────────────────┘     ░░
  ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░
```

Overlay disparado quando o visitante demonstra intenção de sair (cursor rumo ao topo no desktop, scroll para cima no mobile), oferecendo um lead magnet em troca do e-mail. Recupera quem ia embora de mãos vazias.

- **Um único campo.** Só o e-mail — formulário longo na saída não converte.
- **Botão de fechar visível.** No canto superior direito; popup difícil de fechar irrita e afasta.
- **Uma vez por sessão e por página.** Segmente a oferta conforme a página; evite fadiga.
- **Expectativa realista.** Converte ~2–5% de quem sairia. É recuperação, não milagre.

---

## Antes de publicar

- **Teste, não confie só na intuição.** Headline, CTA e tamanho do formulário são os elementos de maior impacto — rode A/B testes nesses primeiro.
- **Velocidade e mobile primeiro.** Carregamento rápido e experiência mobile fluida deixaram de ser diferencial e viraram pré-requisito.
- **Sobre os números.** Os percentuais de conversão de referência vêm de blogs de mercado e servem como direção; o que vale para o seu caso só o teste no seu próprio tráfego confirma.
